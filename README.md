# Hospital Data Analysis using PostgreSQL

## 📌 Project Overview

This project analyzes hospital data using PostgreSQL to extract
meaningful insights related to patients, doctors, departments,
medical expenses, and patient stay duration.

## 🛠️ Tools & Technologies

- PostgreSQL
- SQL
- CSV

## 📊 Key SQL Concepts Used

- SELECT
- WHERE
- GROUP BY
- ORDER BY
- LIMIT
- SUM()
- AVG()
- MAX()
- DATE calculations
- DATE_TRUNC()
- Aggregate functions

## 🔍 Analysis Performed

- Total patients across hospitals
- Average doctors available in each hospital
- Top 3 departments by patient count
- Hospital with highest medical expenses
- Average medical expenses per day
- Longest patient stay
- Patients treated by city
- Average stay duration by department
- Department with least patients
- Monthly medical expenses

## 📁 Files

- `hospital_data_analysis.sql` – SQL queries
- `Hospital_Data.csv` – Dataset

## 🎯 Objective

To practice SQL querying and perform practical analysis
on hospital-related data using PostgreSQL.
